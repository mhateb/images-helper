# Аналитика

[← к кейсу](../README.md)

Яндекс.Метрика подключается только после согласия в баннере. Пока человек не нажал «Принимаю», тег `mc.yandex.ru` в документ не попадает. «Только необходимые» записывает отказ, и цели тоже не отправляются.

Как это устроено в коде — в разделе [«Что интересного технически»](../README.md#что-интересного-технически). Здесь только то, что нужно, чтобы счётчик заработал.

## Счётчик

| Переменная | Где читается | Зачем |
|------------|--------------|--------|
| `VITE_YM_ID` | Сервер в рантайме, запасной путь — сборка Vite | Номер счётчика |
| `YM_ID` | Только сервер, если `VITE_YM_ID` пустой | Тот же номер, удобно в окружении хостинга |

Сервер пишет в HTML `window.__FITPIX_YM_ID__` на каждый ответ. Поэтому номер можно задать на этапе запуска контейнера и не пересобирать образ. На Amvera это переменная этапа **Запуск**.

Клиент берёт id сначала из `window.__FITPIX_YM_ID__`, затем из `import.meta.env.VITE_YM_ID`. Ноль или пустое значение — аналитика выключена, баннер при этом всё равно можно закрыть.

## Цели

В кабинете Метрики создайте цели типа «JavaScript-событие» с этими идентификаторами:

| Идентификатор | Когда срабатывает |
|----------------|-------------------|
| `file_upload` | В очередь добавлены файлы |
| `optimize_start` | Нажали оптимизацию |
| `optimize_success` | Сжатие прошло |
| `optimize_error` | Сжатие вернуло ошибку |
| `download` | Скачивание файла или ZIP |
| `queue_limit` | Очередь упёрлась в 20 файлов |
| `guide_open` | Открыт гайд |
| `bug_report_open` | Открыта форма проблемы |
| `bug_report_submit` | Багрепорт ушёл |
| `analyze_start` | Запущен анализ URL |
| `analyze_success` | Анализ посчитал страницу |
| `analyze_error` | Анализ не удался |
| `analyze_zip_start` | Запрошен ZIP оптимизированных картинок |
| `analyze_zip_success` | ZIP собран |
| `analyze_zip_error` | ZIP не собрался |
| `analyze_open_in_tool` | Картинку со страницы открыли в редакторе |

Хиты SPA отправляются при смене маршрута (`/`, `/guide`, `/analyze`, `/privacy`), отдельной перезагрузки документа для этого не нужно.
